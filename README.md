# Card Validator

This is a my second project which will be able to numerically check if a given credit/debit card is valid or not

## Project

This is a console based project built in Kotlin.
- Built this project to learn the basic syntax and methods of Kotlin
- This program contains no File Input or Output
- This program works on the basis of Luhn's algorithm


**What this project taught me?**
- How banking application optimize load in their servers by numerically validating a card
- How the Luhn's Algorithm works
- How to apply text written algorithm in my program
